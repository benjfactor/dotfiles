Level is composition depth only — what builds on what. Whether a plugin is publishable is a separate axis, set per card. An org-specific plugin can sit at any level: notify-pr-channels is Vendasta-specific and still a level-2 workflow, because the PR flow depends on it rather than the other way round.

    
Optional edges are orange. Claude Code has no peerDependencies — the validator reports it as an unknown field ignored at load time — so every orange edge is either an over-requiring hard dependency or unenforced prose.

    
A renamed plugin emits a renames entry in the manifest below, since a rename target must resolve to a name in plugins[], another renames key, or null.

    
Description is published — it becomes the plugin’s description in the manifest and is what a consumer reads when choosing to install. Notes are never published and never reach the manifest; they exist only to brief Claude, and Copy brief for Claude collects them along with the current grouping.

    
Token figures are always-on cost measured from each skill’s frontmatter at roughly 4 characters per token. Your grouping, names, descriptions and notes are saved in this browser only — they never reach Claude unless you paste the brief.
